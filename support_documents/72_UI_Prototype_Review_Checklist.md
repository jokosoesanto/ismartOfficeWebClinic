# 72 UI Prototype Review Checklist

> [!IMPORTANT]
> Dokumen ini harus digunakan secara berpasangan bersama dokumen *Discovery Report* sebelumnya saat fase UI Parity.

## Instruksi UAT untuk Stakeholder
Harap buka seluruh menu dan periksa poin-poin berikut sebelum mengajukan *Change Request* (Backlog).

- [ ] **Navigasi Terbuka Mulus**: Tiada error merah 500.
- [ ] **Kelengkapan Toolbar**: Terdapat kolom pencarian dan tombol utama.
- [ ] **Layout Responsif**: Perbesar dan perkecil layar (resize browser) tidak merusak grid.
- [ ] **Theme Switching**: Coba ganti tema dari Menu Header, apakah layout prototipe tetap tampil dengan warna yang sesuai?
- [ ] **Watermark**: Terdapat kotak *alert* abu-abu bertuliskan `Dummy Data Placeholder` dan badge `Prototype 0.1`.
- [ ] **Parity Gap**: Apakah komponen yang di-mockup mewakili minimal 70% struktur data yang selama ini dilihat di aplikasi *Clinic Desktop* lama? (Catat kekurangannya untuk Sprint *Business Logic*).
