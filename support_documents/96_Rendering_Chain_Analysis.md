# Full Rendering Chain Analysis

This document proves the exact point where the new Template loses control of the rendering process.

## Chain of Events (e.g., GET /Patient)

1. **Controller (`PatientController.Index`)**
   - Creates `UIMetadata`.
   - Adds `UIComponent` with `ComponentId = "DataGrid"` to `Composition.Center`.
   - Returns `View("Templates/Patient_List", meta)`.
   - **Status: PASS.** Correct Template is referenced.

2. **Metadata Contract**
   - The metadata successfully arrives at the View Engine containing the `Center` component definition.
   - **Status: PASS.**

3. **Template (`Views/Shared/Templates/Patient_List.cshtml`)**
   - The View Engine locates the file.
   - It sees `Layout = "_RegionLayout";`.
   - The Razor engine processes the HTML content of the template.
   - **Status: PASS.** Template logic executes correctly.

4. **Layout (`Views/Shared/_RegionLayout.cshtml`)**
   - The Layout begins processing.
   - At line 48, the Layout checks: `if (Model.Composition.Center.Any())`.
   - Because the Controller provided a `DataGrid` component, this evaluates to `true`.
   - At line 50, the Layout calls: `IgnoreBody();`
   - **FATAL FLAW:** The `IgnoreBody()` command explicitly discards the entire HTML string generated by `Patient_List.cshtml`.
   - At line 51-54, the Layout loops through the `Center` components and executes them via `ComponentRegistry`.

5. **Region & ViewComponent**
   - `ComponentRegistry` receives `DataGrid`.
   - It invokes the `DataGrid` ViewComponent.
   - The ViewComponent produces its own HTML (the old prototype UI).
   - **Status: FAIL.** The ViewComponent output completely overwrites the Template output.

6. **HTML Response**
   - The browser receives the HTML from the ViewComponent, not the Template.

## Conclusion
The template loses control at **Step 4 (Layout)**. The `_RegionLayout.cshtml` is explicitly programmed to discard the Template's Body (`IgnoreBody()`) if there is any component defined in the `Center` region of the Metadata. Because the controllers were never stripped of their `Center` components during the Template Sprint, the Layout continues to prioritize the old ViewComponents over the new Templates.
